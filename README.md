### Client: Ms. Ayushi Desai & Mr. Amit D

A public-ready, high-performance responsive web presentation deck designed for public deployment on Vercel or any modern static web host.

---

## 🚀 Instant Vercel Deployment

### Method 1: Using Vercel CLI (Fastest)
1. Open PowerShell / Terminal in this project directory:
   ```bash
   cd wedding_deck
   ```
2. Run:
   ```bash
   npx vercel --prod
   ```
3. Follow the 1-click prompts (Defaults are preconfigured in `vercel.json`).

---

### Method 2: Via GitHub / GitLab / Bitbucket
1. Push this directory to your Git repository.
2. In the [Vercel Dashboard](https://vercel.com/new), select **Import Project**.
3. Framework Preset: **Other** / **Static Site**
4. Root Directory: `./` (or leave default)
5. Click **Deploy**.
